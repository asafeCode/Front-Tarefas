# Front-Tarefas

Frontend do aplicativo de **gestão de rotinas e tarefas**, desenvolvido para consumir uma API backend em .NET, com foco em simplicidade, usabilidade e integração eficiente com APIs REST.

## 📌 Visão Geral

A aplicação permite que usuários autenticados gerenciem suas rotinas e tarefas, acompanhando progresso e interagindo de forma fluida com o backend. O projeto foi estruturado para refletir um cenário real de aplicação frontend integrada a um sistema backend seguro.

## ⚙️ Funcionalidades

* Autenticação de usuários
* Listagem, criação, edição e exclusão de tarefas
* Atualização de progresso das tarefas
* Integração completa com API REST
* Interface simples, clara e responsiva

## 🛠 Tecnologias Utilizadas

* **React**
* **TypeScript**
* **Vite**
* **Consumo de APIs REST**
* **Gerenciamento de estado e hooks**

## 🧱 Estrutura do Projeto

O projeto segue uma organização baseada em responsabilidades, separando componentes reutilizáveis, páginas, serviços de API e modelos, facilitando manutenção e evolução do código.

## 🔗 Backend

Este frontend consome a API disponível em:

## 🎯 Objetivo do Projeto

Aplicar na prática a integração frontend/backend, reforçando conceitos de consumo de APIs, organização de código, experiência do usuário e comunicação eficiente entre as camadas.
